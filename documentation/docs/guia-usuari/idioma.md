# Idioma i preferències

## Canviar l'idioma

El selector d'idioma es troba a la part inferior del Sidebar. Pots triar entre:

- **CA** — Català (idioma per defecte)
- **ES** — Castellà
- **EN** — Anglès

El canvi és immediat i s'aplica a tota la interfície sense recarregar la pàgina. La preferència es guarda al navegador i es manté entre sessions.
