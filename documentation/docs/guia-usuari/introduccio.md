# Introducció

Keyly permet gestionar les credencials de l'empresa de manera segura i centralitzada. Pots desar contrasenyes, organitzar-les en carpetes i compartir-les amb companys de feina amb permisos diferenciats.

## Conceptes bàsics

**Ítem** — Una credencial: conté títol, nom d'usuari, contrasenya, URL i notes opcionals. La contrasenya sempre es guarda xifrada.

**Carpeta** — Un contenidor que agrupa ítems relacionats. Pot compartir-se com a unitat.

**Compartit** — Un ítem o carpeta que un usuari ha cedit a un altre amb un nivell de permís determinat.

## Rols d'usuari

| Rol | Descripció |
|---|---|
| `USUARI` | Accés bàsic: gestiona les seves pròpies credencials |
| `CAP` | Pot veure i gestionar usuaris, departaments i sucursals |
| `ADMIN` | Control total: accés a tots els compartits i configuració global |

El teu rol apareix al costat del nom d'usuari a la capçalera de l'aplicació.
