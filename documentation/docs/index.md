# Keyly — Documentació

Keyly és un gestor de credencials corporatiu que permet emmagatzemar, organitzar i compartir contrasenyes de forma segura dins d'una organització.

Totes les contrasenyes es xifren al navegador de l'usuari abans d'enviar-se al servidor. Ni el backend ni cap administrador de sistema pot llegir les credencials en text pla.

## Tecnologies

| Capa | Tecnologia |
|---|---|
| Frontend | React 18, TypeScript, Material UI v6 |
| Enrutament | React Router v7 |
| Criptografia | Web Crypto API (RSA-OAEP + AES-GCM + PBKDF2) |
| App Android | Android Java |
| Internacionalització | i18next |
| Backend | Spring Boot (Java) |
| Autenticació | JWT Bearer Token |
