# Internacionalització (i18n)

La internacionalització es gestiona amb `i18next` i el plugin `react-i18next`. La configuració es troba a `src/i18n.ts`.

## Idiomes suportats

| Codi | Idioma | Fallback |
|---|---|---|
| `ca` | Català | — (idioma per defecte) |
| `es` | Castellà | `ca` |
| `en` | Anglès | `ca` |

## Namespaces

Cada àmbit funcional té el seu fitxer de traducció independent per evitar fitxers monolítics.

| Namespace | Contingut |
|---|---|
| `auth` | Textos del login i recuperació |
| `home` | Tauler principal |
| `item` | Gestió d'ítems |
| `folder` | Gestió de carpetes |
| `shared` | Compartits |
| `stats` | Estadístiques |
| `config` | Configuració i perfil |
| `sidebar` | Navegació lateral |
| `common` | Textos transversals (botons, errors genèrics) |
| `card` | Targetes de credencial |
| `share` | Modal de compartició |
| `toolbar` | Barra d'eines |
| `choose` | Selector de tipus |

## Ús als components

```tsx
const { t } = useTranslation('item');
// ...
<Typography>{t('create.title')}</Typography>
```

El detector de llengua comprova primer `localStorage`, després les preferències del navegador i finalment cau al català.
